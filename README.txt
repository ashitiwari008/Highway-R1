Highway Engineering Practice Tool v4
==================================
Files:
- index.html: app interface
- app.js: quiz logic, randomized answer order, timer mode
- questions.json: 30 starter MCQs
- manifest.json, sw.js, icon.svg: PWA install/offline shell

Important:
1. This is a starter question bank, not a completed 10,000+ bank.
2. Some questions are general engineering practice and marked verified:false. Do not treat their references as exact clause citations.
3. Official listing title questions marked verified:true are checked against IRC official publication listing; technical provisions still require full applicable publication.
4. For best iPhone support, host the extracted files at an HTTPS URL (GitHub Pages works), open in Safari, Share > Add to Home Screen.
5. JavaScript timer runs only while the page is active. Closed/locked push notifications require a push server and subscription setup; this package does not provide background push.
6. Before using for design/contract decisions, check latest IRC edition, amendments/errata, MoRTH specification and project agreement.
